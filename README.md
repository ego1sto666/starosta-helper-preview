# Помощник старосты — демонстрация группы 26-ИВТ-2-1

ФИО 37 студентов взяты из выгрузки состава группы. Расписание основано на открытых данных НГТУ. Дела, посещаемость и оценки созданы случайно для показа и не отражают реальные результаты студентов. Контактов студентов нет. Аккаунты, почта и сервер в этой версии отключены.

Основной проект разрабатывается отдельно; данные, которые вы вводите здесь, остаются в вашем браузере.
